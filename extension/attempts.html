Was it ever off?

Loading…

The extension notes the time whenever it is running: when it starts, on every page it sees, and once a minute. A silence means it wasn’t running; this browser’s own history says whether the browser was in use meanwhile, since a closed browser or a sleeping computer leaves the same silence. A visit to a listed site found in the history is placed the same way: from before the extension was installed, from a time it was off, or from a time it was running, so the site wasn’t on a list yet. The settings page says whether the Firefox lock, which takes the switch away, is in force.
