    Safe search

    A list can’t filter search results, so searches on the big search engines are sent with the engine’s own strict filter switched on, whatever its settings say, and YouTube is kept in Restricted Mode. Other search engines, and sites with a search of their own, aren’t covered.

    Search Google for “test”

    The address should gain safe=active, which makes Google leave explicit results out. An ordinary search like this one shows nothing more; for an explicit search, Google Images also says above the results: “SafeSearch is locked to filter by safety settings applied to this browser.” Google’s own SafeSearch settings show the account’s setting, which this extension leaves alone, so they may still say Blur or Off.

    Blocked attempts

    Each time a site on either list is opened in a tab, it’s noted with the time. If the site got through instead of being blocked, the note says so: then something above still needs switching on. Visits from before the extension was watching, or before a site was listed, are added from this browser’s own history when the extension is installed or updated, marked as found there. The latest few are below; the whole record, summed up by site and day, has a page of its own. Nothing on either page can clear the record.

    Once a try is in the record, the site’s pages are taken out of this browser’s own history, and bookmarks to listed sites are removed, so the address bar stops suggesting them. The record is the place to look for them.

    Locked-away password

    Keep a password here that you can only get back after a wait you choose, such as this computer’s administrator password. The wait is real computing: the computer has to work through a puzzle that can’t be skipped, so reading the extension’s storage or changing the clock doesn’t get the password out sooner.

    Removing the extension deletes the locked-away password with it, and so does Firefox when it quits if the add-on isn’t signed. Keep a backup file: it stays locked with the same wait.

    It’s already locked away again with the same wait. It stays on this page until you click Hide or close the page.
