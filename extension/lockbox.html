Locked-away password

Keep a password here that you can only get back after a wait you choose, such as this computer’s administrator password. The wait is real computing: the computer has to work through a puzzle that can’t be skipped, so reading the extension’s storage or changing the clock doesn’t get the password out sooner. More about how it works and what it can’t do.

The password

The wait is already the longest offered.

Making the wait longer needs no unlocking: the locked box goes inside a longer puzzle. Making it shorter needs the password, so that can only be done once it has been unlocked. A backup file saved before the wait was lengthened can’t be changed: restored here it gets the longer wait, since this browser profile remembers the boxes that have held the password and the wait set for it, but on another profile or computer it still opens after the old wait. Delete it (and empty the Trash) or make up a new password, and save a new backup file.

Removing the extension deletes the locked-away password with it, and so does Firefox when it quits if the add-on isn’t signed. Keep a backup file: it stays locked with the same wait.

Copied

It’s already locked away again with the same wait. It stays on this page until you click Hide or close the page.

A shorter wait can only be chosen here, once the old one has been served. A longer one can be chosen at any time without unlocking: Lengthen the wait, shown while the password is locked away.

What has happened

Everything done with the locked-away password on this page, with the time, newest first: locked away, unlocking started, carried on or stopped, the password shown and locked away again, a backup file restored, the password deleted. The record stays when the password is deleted or replaced, and nothing on this page can clear it.
